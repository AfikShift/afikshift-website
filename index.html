How to install

  1. Download the APK on your Android phone.
  2. Open the downloaded file. If asked, allow your browser or Files app to "install unknown apps".
  3. Tap Install (or Update if AfikShift is already installed). Your data is kept.
  4. Open AfikShift and sign in.

To update, never uninstall first: install the new version over the old one. Only download AfikShift from afikshift.com, and check the SHA-256 checksum above if you want to confirm the file is genuine.
